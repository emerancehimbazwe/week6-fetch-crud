# CRUD Posts Manager

A responsive CRUD application built with JavaScript Fetch API, Vite, and Tailwind CSS.

## Project Overview

CRUD Posts Manager allows users to interact with posts using HTTP requests through the JSONPlaceholder API.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- Fetch API
- Vite
- JSONPlaceholder API

## Features

- **GET:** Fetch and display posts from the API.
- **POST:** Create new posts.
- **PATCH:** Update post titles.
- **DELETE:** Delete posts with confirmation.
- **User Filtering:** Filter posts by user ID.
- **Title Search:** Search loaded posts by title.
- **Loading and Error Handling:** Display request status and error messages.
- **Request Timeout:** Stop requests that take longer than 8 seconds.

## Installation

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL provided by Vite.

## API

This project uses [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

**Note:** JSONPlaceholder simulates POST, PATCH, and DELETE requests. Changes are not permanently saved on its server.
